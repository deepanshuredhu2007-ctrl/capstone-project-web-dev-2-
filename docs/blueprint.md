# **App Name**: JobTrack Pro

## Core Features:

- Secure User Accounts: User registration and login with role-based access (Admin, Viewer) using Firebase Authentication for secure access.
- Application Management (CRUD): Full create, read, update, and delete (CRUD) functionality for job applications, including a comprehensive form to capture company name, role, status, platform, location, salary, applied date, and notes.
- Intelligent Note & Feedback Assistant: An AI tool that provides suggestions for application notes or helps draft personalized feedback based on the job details and current application status.
- Interactive Job Dashboard: A dynamic dashboard providing visual summaries with summary cards for total applications, interviews, offers, rejections, and charts showing application status distribution.
- Dynamic Application List: A sortable and filterable table/list view of job applications with search functionality, debounced API calls for efficiency, and either pagination or infinite scrolling for large datasets.
- Responsive Design & Theme Toggle: A responsive user interface that adapts seamlessly to desktop and mobile devices, complemented by a user-controlled dark mode toggle for personalized viewing.

## Style Guidelines:

- Primary Color: Professional and calm blue (#3A7EAC) to signify clarity and focus in tracking career progress.
- Background Color: A light, almost imperceptible grey-blue (#F4F7F8) providing a clean and distraction-free canvas for data.
- Accent Color: A vibrant, fresh green-cyan (#49DBAD) to highlight interactive elements and positive actions, suggesting growth and new opportunities.
- Headline Font: 'Space Grotesk' (sans-serif) for a modern, tech-savvy, and distinctive appearance, reflecting the 'Pro' aspect of the app.
- Body Font: 'Inter' (sans-serif) for high readability across data tables, forms, and general text, maintaining a neutral and objective feel.
- Modern, minimalist line icons that clearly communicate functionality like filtering, sorting, editing, and various application statuses (e.g., checkmarks, crosses, arrows).
- A clean, spacious, and grid-aligned layout focused on hierarchical information display. Ample whitespace ensures readability and reduces visual clutter on dashboards and lists.
- Subtle and quick transitions for state changes, such as loading indicators for data fetches, form submission feedback, and smooth shifts between UI elements to enhance the user experience without being obtrusive.
